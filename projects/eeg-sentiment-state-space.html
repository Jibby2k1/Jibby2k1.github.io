Overview

Pipeline that turns brain-wave recordings (EEG) into a small set of hidden time-series ‘states’ using a state-space model (Hierarchical Linear Dynamical System, HLDS), then evaluates those states for prediction and separability.

In this work, I focused on making brain-signal modeling practical: take raw EEG recordings collected while participants view media, clean and standardize them, fit a time-series model that tracks a few hidden variables over time, and produce clear metrics and reports so results are comparable across sessions and subjects.

This project turns messy EEG recordings into a compact, moving summary of brain state that you can actually evaluate.

What problem is this solving?

EEG is cheap, non-invasive, and extremely noisy. When you record it while someone watches media, the interesting structure — how a person's internal state shifts over time — is buried under muscle artifacts, drift, and large differences from one subject to the next. The goal here is to recover a small number of hidden variables that track that state cleanly enough to test against labels.

The emphasis is on practical brain-signal modeling: not a demo that works on one clean recording, but a pipeline that stays honest across sessions and subjects.

Why a state-space model?

Rather than throw a large black-box network at the raw signal, I use a Hierarchical Linear Dynamical System (HLDS). It assumes the EEG is generated by a few latent variables that evolve smoothly over time, and that assumption is a feature rather than a limitation: the hidden states stay interpretable, the model needs far less data than a deep network, and you can directly inspect whether the learned dynamics are stable.

When the question is what the brain is doing over time, a model whose internal variables you can read is worth more than a slightly higher benchmark number you cannot explain.

How the model is trained and used

The HLDS runs in two clearly separated phases. In training, it learns its parameters with a dual-Kalman-filter procedure: it alternates between inferring the hidden states and updating the model parameters, repeating over multiple passes through the data. At inference time those parameters are frozen, and a Kalman-style recursion runs bottom-up to infer the hidden-state trajectory for a new recording. Those trajectories become the compact encodings the classifier reads.

Splitting learning from inference this way is what keeps evaluation honest: the encodings a downstream classifier sees are produced under fixed parameters, not quietly re-fit to each test recording.

The pipeline around the model

Each experiment is a fixed sequence of stages, so a result from one subject or session can be compared fairly against another:

Preprocessing
Clean, standardize, and align raw recordings into consistent time windows the model can consume.
Training
Fit the HLDS parameters with the dual-Kalman procedure over multiple passes.
Post-processing
Turn inferred states into the encodings and summaries used downstream.
Classification
Evaluate how well those encodings predict and separate the conditions of interest.
Analysis (EDA)
Stability checks, diagnostics, and plots so a run can be audited, not just scored.

One model, several experiment tracks

The same core model is run across a few parallel tracks so results can be cross-checked rather than resting on a single configuration:

  • Single-channel — isolate what one channel can carry before scaling up.
  • Multi-channel EEG — the full scalp montage as a joint signal.
  • Multi-modal — EEG together with pupillometry, so a second physiological stream can corroborate the brain-state estimate.

What the system is for

The goal of the system is classification: turning the HLDS-derived hidden-state encodings into predictions of the condition or brain state, judged by how well those encodings separate the classes of interest. This is active research inside a collaboration, so the page stays at the level of the model and the pipeline — the HLDS and the classification goal it feeds — rather than reporting numbers.

FAQ

What makes it 'hierarchical'?

The state-space structure is layered so that higher-level hidden variables summarize the behavior of lower-level ones, which is what lets a small number of states stand in for many EEG channels.

Why not just use a deep neural network?

With limited, noisy data and a need to explain what the model is tracking, a linear dynamical system wins on interpretability and data efficiency — you can inspect the states and check that the learned dynamics are stable, which a black box does not give you.

What is LB3?

An internal codename tied to this collaboration. I keep the specifics deliberately vague on the public site.

Can this read emotions?

It tracks brain-state structure that correlates with labeled conditions. Calling that 'emotion detection' would be overclaiming what the signal supports.

What I built

  • A reproducible data pipeline (loading → cleaning → segmentation → feature preparation) that turns raw EEG into model-ready inputs.
  • Training and evaluation scripts for a state-space model called a Hierarchical Linear Dynamical System (HLDS), used to track hidden ‘brain state’ trajectories.
  • Diagnostics and scoring outputs (e.g., stability checks, prediction metrics, and class/condition separability summaries).
  • Automated summaries and artifacts so runs can be audited and compared (configuration capture, standardized outputs, and plots).

How it works

  • EEG is cleaned and aligned into consistent time windows.
  • The HLDS model learns hidden variables that evolve over time and explain the observed EEG signals.
  • Those hidden variables (and model outputs) are evaluated against labels/conditions to test whether the model captures meaningful structure.

Deliverables

  • Run folders with configs, logs, metrics, and plots.
  • A standardized summary table used for comparison across papers/conditions.

Glossary

EEG
Electroencephalography: non-invasive measurement of brain electrical activity from the scalp.
HLDS
Hierarchical Linear Dynamical System: a state-space model that represents a signal using a small set of hidden variables that change over time.
State-space model
A model that explains observations using hidden variables (‘state’) plus rules for how those variables evolve over time.
LB3
An internal project codename tied to this collaboration; kept deliberately vague on the public site.
